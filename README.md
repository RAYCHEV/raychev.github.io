# My Personal Portfolio

Welcome to my personal portfolio. This site is static HTML, CSS, and JavaScript, hosted on GitHub Pages.

## Local preview

Open the files in a browser, or serve the project root:

```bash
npx --yes serve .
```

Pages:
- `/` — Live Projects (GitHub Pages default)
- `/live-projects/` — redirects to `/`
- `/discontinued/` — Discontinued (older work and screenshots)
- `/cv/` — CV
- `/csv-viewer/` — CSV Viewer
- `/contact/` — Contact

## Deploy

Push to the GitHub Pages source branch (usually `main`). No build step is required.
