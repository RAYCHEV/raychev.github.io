Shortcuts

Hold Cmd or Alt and the key shows on each button. Either one works. Lock also accepts Л.

  • Shortcuts?
  • Hide or show menuM
  • Dark / LightD
  • BrowseB
  • New tableN
  • Add, then new / row / column / file / pasteANRCBP
  • Fit columnsF
  • Back / ForwardZ⇧Z
  • Delete table⌫
  • ExportE
  • Copy table⇧E
  • Select / copy selectedS⇧C
  • Create / cancel⏎Esc

Cmd or Alt A opens Add. N opens New: a blank table, a file that replaces the current one, or pasted CSV that replaces it. B and P on the Add menu add rows to the end. While locked, the icon beside a row or column copies it. A cell click copies that cell, unless Select is on.
