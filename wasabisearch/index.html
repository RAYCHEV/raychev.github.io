WasabiSearch Support

WasabiSearch is an iOS application designed to help you quickly search for files stored in your own Wasabi S3-compatible cloud storage.

The app connects directly to your Wasabi account using credentials provided by you and searches object filenames within the selected bucket.

Getting Started

To use WasabiSearch, you need:

  • A Wasabi account
  • An Access Key ID
  • A Secret Access Key
  • The correct Wasabi endpoint/region
  • Access to at least one storage bucket

You can create and manage access keys from your Wasabi account.

Setting Up a Connection

Open WasabiSearch and go to Settings.

Create a new credential profile and enter:

  • Profile name
  • Access Key ID
  • Secret Access Key
  • Endpoint
  • Region
  • Service
  • Bucket

Your credentials are stored securely in the iOS Keychain.

WasabiSearch can also retrieve the list of buckets available to the supplied credentials.

Searching for Files

From the main screen:

  1. Select the required profile or bucket.
  2. Enter part or all of a filename.
  3. Start the search.

The search is case-insensitive and matches the filename rather than requiring an exact full path.

For example, searching for:

WF27174

can find an object such as:

backups/projects/2026/WF27174-document.pdf

Results appear progressively while the bucket is being scanned.

You can stop a running search at any time.

Search Results

Search results display the paths of matching objects.

You can:

  • Copy an individual result
  • Copy all results
  • Stop an active search
  • Start another search

WasabiSearch does not modify or delete objects in your bucket.

Troubleshooting

No buckets are displayed

Check that:

  • Your Access Key ID and Secret Access Key are correct.
  • The selected endpoint and region match your Wasabi storage region.
  • The credentials have permission to list the required buckets.

Search returns no results

Check the spelling of the filename or try searching using a smaller part of the name.

Remember that WasabiSearch searches object filenames and the search is case-insensitive.

Authentication or connection error

Verify your Access Key ID, Secret Access Key, endpoint and region.

Network access is also required to communicate with the Wasabi S3-compatible service.

Search takes a long time

Large buckets can contain many objects. WasabiSearch uses S3 ListObjectsV2 pagination to scan the bucket, so searching very large buckets may take some time.

Results are displayed progressively as matching objects are discovered.

Security & Privacy

WasabiSearch connects directly to the configured S3-compatible service.

Access credentials entered into the app are stored securely using the Apple Keychain.

The application does not require your Wasabi account password.

You should use access credentials with only the permissions necessary for the operations you intend to perform.

For full details, see the WasabiSearch Privacy Policy.

Need Help?

If you experience a problem with WasabiSearch, please contact support and include:

  • App version
  • iOS/iPadOS version
  • Device model
  • Wasabi region/endpoint
  • A short description of the problem

For security reasons, never send your Secret Access Key when requesting support.
