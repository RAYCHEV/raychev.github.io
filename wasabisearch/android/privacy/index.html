Privacy Policy — WasabiSearch for Android

Last updated: October 25, 2026

1. Introduction

WasabiSearch for Android (“the Application”) is an independent application developed by TheXcoder.

The Application allows users to search for files stored in Wasabi cloud storage and compatible S3 storage services.

We respect your privacy and are committed to protecting your information.

This Privacy Policy explains how the Application accesses, processes, stores and protects information.

2. Information Processed by the Application

To provide its functionality, WasabiSearch processes information supplied by the user, including:

  • S3 Access Key ID.
  • S3 Secret Access Key.
  • Storage endpoints and regions.
  • Bucket names.
  • Connection profile settings.
  • Search queries.
  • File names and object paths returned by storage services.

This information is used to establish authenticated connections and perform storage searches.

3. Credential Storage

Storage credentials are required to authenticate requests to the user’s configured S3-compatible storage service.

Credentials and connection settings are stored locally on the user’s device.

The Application does not operate a developer-controlled server for storing storage credentials.

Users should protect their devices and avoid sharing storage credentials with unauthorised individuals.

4. Network Communication

WasabiSearch communicates directly with storage endpoints configured by the user.

These connections are necessary to:

  • Authenticate storage requests.
  • Discover accessible storage buckets.
  • Retrieve object listings.
  • Search for matching filenames.
  • Display search results.

Storage providers may process connection information, including IP addresses and request metadata, according to their own privacy policies.

The Application does not intentionally transmit storage credentials to the developer.

5. File Access

WasabiSearch is designed to search object names and paths.

The Application does not need to download the contents of files to perform filename searches.

Search results may contain filenames and object paths associated with the user’s storage account.

6. Data Sharing

WasabiSearch does not sell personal information.

Information required to perform searches is transmitted to the storage provider selected by the user.

The developer does not intentionally collect copies of storage credentials, search queries or search results through a developer-operated backend.

7. Data Retention and Deletion

Connection profiles and application preferences are retained locally for the purpose of providing the Application’s functionality.

Users can remove saved connection profiles through the Application’s available profile management features.

Uninstalling the Application generally removes its application-specific local data, subject to Android backup and restoration behaviour.

Data stored with third-party storage providers is managed independently by those providers.

8. Security

WasabiSearch is designed to minimise unnecessary access to user information.

The Application uses authenticated requests to communicate with configured S3-compatible storage services.

Users are encouraged to:

  • Use credentials with the minimum required permissions.
  • Avoid using unrestricted administrator credentials.
  • Keep their Android devices updated.
  • Protect their devices against unauthorised access.
  • Revoke compromised credentials through their storage provider.

No software or network communication system can guarantee absolute security.

9. Third-Party Services

WasabiSearch is compatible with Wasabi cloud storage and potentially other S3-compatible storage providers.

These services operate independently and maintain their own privacy policies and data handling practices.

WasabiSearch is not affiliated with Wasabi Technologies.

10. Children’s Privacy

WasabiSearch is a technical utility intended for users who manage cloud storage resources.

The Application is not specifically designed for children.

11. Changes to This Privacy Policy

This Privacy Policy may be updated to reflect changes in Application functionality, security practices or applicable requirements.

Updates will be published on this page with a revised effective date.

13. Disclaimer

WasabiSearch is an independent third-party application.

It is not developed, sponsored, endorsed or officially supported by Wasabi Technologies.
