WasabiSearch for Android — Support

Welcome to the official support page for WasabiSearch for Android.

WasabiSearch is an independent application designed to help users quickly find files stored in Wasabi cloud storage and compatible S3 storage services.

The application provides a simple interface for searching files by name without manually navigating through directories.

Download

WasabiSearch for Android is distributed directly as an APK file.

Download WasabiSearch for Android

  • Platform: Android
  • Version: 1.0.0
  • Distribution: Direct APK download

Installation

  1. Download the APK file to your Android device.
  2. Open the downloaded file.
  3. If Android requests permission to install apps from this source, follow the device instructions.
  4. Confirm the installation.
  5. Open WasabiSearch.

Android may display a security warning because this version is not distributed through Google Play.

Only download WasabiSearch from the official download button on this page.

Features

  • File Search: Search for files by filename across your configured storage bucket.
  • Recursive Search: Search through folders and subfolders.
  • Progressive Results: View matching files as they are discovered.
  • Multiple Profiles: Configure and manage different storage connections.
  • Flexible Configuration: Specify storage endpoints, regions and buckets.
  • Copy File Paths: Copy individual file paths or multiple search results.
  • Search Cancellation: Stop an ongoing search whenever necessary.
  • Secure Credentials: Store access credentials using Android’s secure storage mechanisms, where supported by the implementation.

Getting Started

  1. Install WasabiSearch on your Android device.
  2. Open the application.
  3. Create a storage connection profile.
  4. Enter your S3-compatible storage credentials.
  5. Configure your endpoint, region and bucket.
  6. Save your configuration.
  7. Enter a filename or part of a filename to begin searching.

Search results appear progressively as matching objects are discovered.

Frequently Asked Questions

Does WasabiSearch store my files?

No. WasabiSearch is designed to search storage objects and display matching file paths. It does not provide independent cloud storage.

Does the application upload my files?

No. The application does not upload files as part of its search functionality.

Can I use multiple storage accounts?

Yes. WasabiSearch supports multiple connection profiles.

Why is my search taking a long time?

Search performance depends on several factors, including:

  • The number of objects stored in your bucket.
  • Your internet connection.
  • Storage service response times.
  • The number of folders and objects that must be examined.

Large buckets may require additional time to search.

Why can’t I connect to my storage?

Please verify:

  • Your Access Key ID and Secret Access Key.
  • Your configured endpoint and region.
  • Your bucket name.
  • Your account permissions.
  • Your internet connection.

Your storage credentials must have the permissions required to list objects in the selected bucket.

Is WasabiSearch an official Wasabi application?

No. WasabiSearch is an independent third-party application and is not affiliated with, endorsed by or sponsored by Wasabi Technologies.

Technical Support

If you experience problems, discover bugs or would like to suggest improvements, please contact the developer through the contact page.
